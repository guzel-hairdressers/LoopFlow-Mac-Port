# Long-Term Technical Proposals & RFCs (`docs/proposals`)

This directory houses formal, long-term technical design proposals, Architecture Decision Records (ADRs), and Request for Comments (RFCs) for major feature additions or structural refactors.

## Document Naming Standard

Format: `RFC-XXX-short-title.md` or `ADR-XXX-short-title.md` (e.g. `RFC-001-live-sync-protocol.md`).
